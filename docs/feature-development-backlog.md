# 開発中の機能と保留タスク

## スポット発行

- 現在の画面実装は試作段階。月次発行との区別、スポット請求書の個別CSV出力、計上月の変更、請求明細・入金明細の表示切替を確認できる。
- 詳細仕様は後日確定する。確定後に画面構成、発行・再発行、計上月の変更運用、入金照合との関係を見直す。

## 敷金管理・仲介料管理

- 敷金はオフィス新規契約の対応依頼確定時に、契約区画の敷金額を元に営業部の期日回答・総務経理部の請求タスクを作る。管理表と請求書作成画面で月次／スポットを選ぶ試作を追加した。
- 敷金のDB Migrationはリモート環境への適用が必要。営業部・総務経理部の本番業務画面への移動、敷金の契約変更・取消時の扱い、入金照合は今後詰める。
- 仲介料は敷金の仕様がまとまってから着手する。
