# 全社運用ダッシュボード

トップ画面は固定値を持たず、Supabaseの業務テーブルから契約・レントロール・発注支払・LCC・収支実績・AppSuite同期を横断集計します。

## 表示内容

- 全社KPI：月額契約収入、区画稼働率、要対応件数、確定・計画支出
- 優先アラート：同期停止、外部連携の未照合、対応依頼、支払超過、契約終了、LCC期限、収支データ未整備
- データ整備状況：AppSuite同期、月次実績、公開シナリオ、LCC、契約終了予定
- 月別資金見通し：過去5か月の収支実績と、当月から11か月先までの契約収入・支払予定・LCC計画
- 物件別比較：稼働区画、稼働率、月額契約収入、発注残、未払、12か月LCC、年度実績収支

## 集計ビュー

| ビュー | 用途 |
| --- | --- |
| `operations_dashboard_summary` | 全社KPIを1行で返す |
| `operations_dashboard_alert` | 各業務領域の優先アラートを統合する |
| `operations_cashflow_monthly` | 過去実績と今後の既知資金見通しを月別に返す |
| `operations_property_snapshot` | 物件別の稼働・収支・支出計画を比較する |

すべてのビューは `security_invoker = true` です。基礎テーブルのRLSを引き継ぎ、有効なログイン利用者だけに `SELECT` を付与します。匿名利用者には公開しません。

## 数値の定義

- 稼働区画：本日時点で有効な契約期間に含まれる区画の重複なし件数
- 月額契約収入：本日時点で有効な契約区画の賃料・共益費合計
- 要対応：未完了の対応依頼と、AppSuite／Bill One受信箱の要確認件数
- 確定・計画支出：未完了発注額、未払予定額、12か月以内のLCC計画額の合計
- 既知資金見通し：過去月は月次実績収支、当月以降は契約収入から支払予定とLCC計画を控除
- 年度実績収支：4月開始年度の収入実績から支出実績を控除

月次実績、LCC、公開済み収支シナリオが未登録の場合は、ゼロを完成値として扱わず「データ未整備」のアラートを表示します。
