# 駐車場Excel取込 標準ひな型

駐車場台帳画面の「標準ひな型」ボタンから `.xlsx` を生成できます。

## 標準列

| 列 | 必須 | 内容 |
| --- | --- | --- |
| 状態 | 必須 | `契約中` または `空き` |
| 枠番 | 必須 | 駐車場施設内の区画番号 |
| 暗証番号 | 任意 | 暗証番号、リモコン番号等 |
| テナント名 | 契約中のみ | 契約先名称 |
| 車種 | 任意 | 車種・車名 |
| 車両番号 | 任意 | 登録番号・ナンバー |
| 車台番号 | 任意 | 車台番号 |
| 契約開始日 | 任意 | Excel日付または YYYY/MM/DD |
| 備考 | 任意 | 補足事項 |

## 取込時の補完

- `状態` が空欄の既存ファイルは、テナント名が空欄なら空き区画として扱います。
- 枠番・テナント名などは代表的な表記ゆれを吸収します。
- 既存Excelに `階`・`所在`・`フロア` 列がある場合は互換項目として読み取りますが、標準ひな型には含めません。
- 契約先候補は選択物件に紐づくテナントを優先表示します。
- 物件内に見つからない契約先は、取込確認画面のキーワード検索から全テナントを検索できます。
