# 売上計上用 CSV 仕様案

状態: 仕様確認中。③請求明細からの売上計上用 CSV 出力を対象とする。

## 参照資料

- ミロク取込 CSV `14.csv`（2026年10月分、31列の仕訳形式）
- `発生主義での売上計上.xlsx`（対象期間別の計上パターン）

上記ファイル内のデータ・文言は業務資料として参照し、仕様の決定は本書と利用者の指示を優先する。実在の取引先名・金額は本書に転記しない。

## 出力対象と粒度

- 請求済みの月次請求書とスポット請求書を対象とする。
- テナント × 請求項目 × 計上日 × 仕訳パターンを基本単位として出力する。異なる請求項目をテナント合計にまとめない。
- 金額には税込の請求金額を用いる。ミロク CSV の借方・貸方消費税コードは空欄とする。
- CSV は参照ファイルと同じ列順・文字コードを基本とする。会計側の実取込で検証する。
- CSV 出力を請求明細の「確定」とする。確定した請求データ、適用した科目設定、出力内容、出力日時、操作者を保存する。確定後の再出力では同じ仕訳を重複出力しない。
- 確定済みの請求を変更する際は確定解除を行う。解除時に、既出力仕訳を会計側で取消・差替えする必要がある旨を警告する。解除・再出力の履歴を残す。

## 科目

| 用途 | 科目コード | 補助科目コード |
| --- | --- | --- |

敷金請求は `未収入金／預り保証金` とする。敷金を賃貸売上へ振り替えない。

## 管理者コンソールのテナント請求設定

既存の「請求種別」に以下を追加する。物件別の明細項目ではなく、共通の請求種別に設定する。

| 設定 | 内容 |
| --- | --- |
| 固定費 | 真偽値。請求種別が固定費かを示す共通設定。本機能では、前月分を請求する際に前月末へ先行して売上計上する対象の判定に使う。 |
| 売上科目コード | 売上へ計上する際の貸方科目。既存種別の初期値は `4100`。 |
| 売上補助科目コード | 売上へ計上する際の貸方補助科目。既存種別の初期値は `1`。 |

- 「その他」には売上科目・売上補助科目の設定欄を設けない。敷金、車庫証明発行手数料、セキュリティカード発行手数料は、それぞれの管理表で請求書明細項目１・２と計上科目・補助科目を設定する。敷金の初期値は預り保証金 `3600`、発行手数料の初期値は賃貸売上 `4100-1` とする。
- 既存種別の固定費フラグは、賃料・共益費・駐車料を有効、その他を無効で初期化する。新規種別は無効で作成する。管理者がテナント請求設定で変更できる。
- 従来、物件別の「請求設定 > 明細項目」に登録した「その他（敷金）」「その他（車庫証明）」は削除する。管理表から請求書作成へ渡す設定と重複させない。
- 前受金から売上へ振り替える仕訳にも、請求種別の売上科目・補助科目を用いる。
- 設定変更が確定済みの出力を遡って変更しないよう、確定時の科目設定を出力履歴に保持する。

## 対象期間別の仕訳

以下は11月1日発行の11月請求分を例とする。売上勘定は請求種別の設定を使う。

| 対象期間 | 仕訳日と内容 |
| --- | --- |
| 当月分 | 11/1：未収入金／売上。 |
| 翌月分 | 11/1：未収入金／前受金。12/1：前受金／売上。12/1の仕訳も11月の CSV に含める。 |
| 前月分 | 10/31：固定費フラグが有効な請求種別の固定費だけ、未収入金／売上。11/1：請求全額を未収入金／売上で計上し、10/31に計上した額と同額を売上／未収入金で戻す。戻し仕訳日は請求日とする。 |
| 年払い・翌月開始 | 11/1：12か月分を未収入金／前受金。12/1から毎月1か月分を前受金／売上へ振り替える。振替は各月の計上に含める。端数は初月で調整する。 |
| 年払い・翌々月開始 | 11/1：12か月分を未収入金／前受金。翌年1/1から毎月1か月分を前受金／売上へ振り替える。振替は各月の計上に含める。端数は初月で調整する。 |

### 年払いの月額配分

- 税抜総額、消費税総額それぞれについて、2～12か月目の基準額を `総額 ÷ 12` の1円未満切り捨てで求める。各月の税込額は税抜額と消費税額の合計とする。
- 初月は `総額 − 2～12か月目の合計` とし、端数をすべて初月へ配分する。初月の税込額は初月の税抜額と消費税額の合計に一致させる。
- 請求時の前受金計上額と12か月の振替仕訳の税込合計を一致させる。

### ミロク CSV の列対応案

提供された `14.csv` の31列を維持し、1仕訳を1行とする。取込時の文字コードは Shift_JIS（CP932）とする。

| CSV 列 | 値 |
| --- | --- |
| 伝票日付 | 上表の計上日。前月分の戻しは請求日。 |
| 借方・貸方科目コード／補助コード | 仕訳パターンと請求種別・管理表の科目設定から決定。 |
| 借方・貸方取引先コード | `billing_code.issue_code` を使う。日本橋の取込見本10件と登録済み発行コード10件の一致を確認済み。 |
| 借方・貸方セグメント1コード | `asset_master.asset_code` を使う。見本の `14` と三共日本橋ビルのアセットコード `14` の一致を確認済み。 |
| 借方・貸方金額 | 同一行の税込金額。税抜・消費税の月額配分は計算根拠として保持する。 |
| 借方・貸方消費税コード、消費税率区分、消費税額 | 空欄。 |
| 摘要 | ビル、テナント、請求項目、対象期間を識別できる内容。 |

例：11月1日発行、12月分の税込11,000円の賃料は、11/1に借方1530／貸方3160で11,000円、12/1に借方3160／貸方4100-1で11,000円を出力する。年払いの後続月の振替は、11月の CSV ではなく各月の計上に含める。
