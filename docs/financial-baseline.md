# 収支ベースライン作成・公開

## 目的

契約、定期収支、LCC、発注残、支払予定を一つの予測シナリオへ統合し、来期以降の収支・資金需要を年度別、月別、物件別に確認できるようにする。

## 操作手順

1. 「収支管理」→「予算・将来予測」で「ベースライン自動作成」を選ぶ。
2. 開始年度と予測年数を指定し、全物件の年度別プレビューを確認する。
3. 「下書きを作成」で編集可能な予測明細を生成する。
4. 物件・月・科目ごとの金額を必要に応じて修正する。
5. 内容を確認後、「確認して公開」を選ぶ。

公開前は必ず下書きとなり、プレビュー操作だけではデータを変更しない。

## 計算対象

| データ | ベースラインでの扱い |
| --- | --- |
| 有効な賃貸借契約の賃料・共益費 | 物件・科目・月ごとの編集可能な予測明細を生成 |
| 定期収支 | 適用期間内の月額を編集可能な予測明細へ反映 |
| 未発注LCC | 発生月の編集可能な予測明細へ反映 |
| 発注残 | 既存の発注・請求データからライブ反映 |
| 未払の支払予定 | 支払予定日を基準にライブ反映 |
| 月次実績 | 既存の月次実績欄へ表示し、予測明細とは分離 |

発注済みLCCは、LCCと発注残の二重計上を避けるため自動生成対象から除外する。発注残と支払予定は、シナリオ作成後も最新状態を参照する。

## 権限

- 有効なログイン利用者: 作成前プレビュー、シナリオ参照
- 管理者・マネージャー: ベースライン作成、シナリオ公開
- 匿名利用者: RPC実行不可

RPCはすべて `security invoker` で動作し、既存テーブルのRLSを継承する。ブラウザへ `service_role` は公開しない。
