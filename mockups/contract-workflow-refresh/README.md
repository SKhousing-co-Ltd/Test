# 契約業務フロー再設計モックアップ

`index.html` をブラウザーで開いてください。単独で動く静的モックアップで、アプリ本体・Supabase DBには接続しません。

## 反映した業務要件

- 契約後進捗を初期表示し、AppSuite申請処理へ同じ画面から切り替え
- 契約ごとに①〜⑤の進捗を表示。物件名・区画・テナント名・契約種別を表示
- 新規契約、定期借家再契約、変更、解約を対象にする。自動更新は対象外
- ①はAppSuite承認後の稟議確認と契約データ作成、②は作成済みデータの内容確認、③は契約書作成、④はBtoB対応、⑤はレントロール反映
- ④は当面、総務経理が完了ボタンで記録。⑤は反映済・スキップ済を完了ボックスで区別
- 不要工程は担当者が理由を記録して手動スキップ
- 解約・変更の詳細パネルで、複数契約の関連付けと変更前後の確認を表現

## 操作

- 「契約後進捗」「申請処理」タブで表示を切り替え
- 案件行または「詳細」から右側の詳細パネルを開く
- 現在工程が④の案件では「BtoB対応を完了」を押して進捗を更新
- 「工程をスキップ」から理由を入力してスキップ済みにする
- 検索と業務種別フィルター、完了案件ボックスの開閉が可能

画面遷移や完了操作は見た目を確認するためのモック動作です。実データの更新は行いません。
