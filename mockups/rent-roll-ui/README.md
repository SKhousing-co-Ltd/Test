# レントロール UI モックアップ

`index.html` をブラウザで開くと、通常利用向けレントロール画面の構成案を確認できます。表示データと集計値は画面案確認用のサンプルで、アプリへの接続はありません。アプリ共通のサイドバーとヘッダーはモックアップに含めず、画面本体を表示します。

## 画面案

- 現在表示と過去スナップショットをタブとして整理し、基準日・物件・検索・絞り込みを一覧の直前に配置。
- 商品区分、状態、区画種別の条件を明示し、集計カードが現在の表示条件に連動することを伝える。
- 一覧は実画面の21列と同じ順序にし、横スクロールで全項目を確認する。
- 一覧の見出しを上部に固定し、状態・商品・種別・階・区画を横スクロール中も左側に残す。テナント名も追従させる。表の中で縦スクロールできる高さを設け、左右移動ボタンとスクロール位置表示も加える。
- 整合性確認は独立画面への導線とし、将来的に管理者コンソールへ移せるよう通常利用の一覧から分離。

## 既存データ取得を維持する場合の設計

- 物件候補は現在と同じく `asset_master` のレントロール表示対象から取得。
- 現行データは `rent_roll_list_with_terms_at_date` RPC、過去データは選択日の最新 `rent_roll_snapshot_batch` と `rent_roll_snapshot_row` から取得。
- 現行表示の公共料金列は既存4系統の設定クエリを維持し、過去表示では非表示。
- 検索・状態・区画種別・商品区分の絞り込みと指標集計は、現在と同じく取得後の行データに対してクライアント側で行う。条件を変えるたびに全データを再取得しない。
- 整合性確認は別ルートに移し、レポート取得と再照合の権限を引き継ぐ。移行時は既存の閲覧・再照合 capability を保つ。

## 次段階の実装候補

本体の一覧表示と整合性確認は別画面に分離し、先頭列の固定と縦横スクロール操作を実装しています。DB/RPCやサーバー側ページングの変更は含みません。
