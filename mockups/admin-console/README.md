# 管理者コンソール モックアップ

`index.html` をブラウザーで開いてください。ログイン画面と管理者コンソールの画面遷移を確認できます。

## 確認できる内容

- ログイン画面にメールアドレス・パスワード欄と「ログイン」「管理者コンソール」の2つの入口を配置
- 「ログイン」から通常業務画面のイメージへ遷移
- 「管理者コンソール」から専用サイドバーを持つ管理画面へ遷移
- コンソール内の管理項目カードから対象項目を選択
- コンソールからログアウトしてログイン画面へ戻る

このモックアップは画面確認用で、認証や実データとの接続はありません。マネージャーも利用する既存機能は通常業務画面側に残す想定です。
